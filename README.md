# 🌟 Akash U P — Personal Portfolio Website

This is the official personal portfolio website of **Akash U P**, designed as part of the Web Programming Laboratory assignment.  
The project showcases my profile, skills, education, projects, achievements, certifications, resume, and a working contact form connected to a database.

---

## 📌 Features

### 🔹 **Left Sidebar Profile Layout**
- Fixed left sidebar with profile picture, name, role, and navigation.
- Clean and modern UI with dark sidebar + light content layout.

### 🔹 **Sections Included**
- **About / Profile**
- **Skills**
- **Education**
- **Projects (Loaded using XML + XSLT)**
- **Achievements**
- **Certifications**
- **Resume Download**
- **Contact Form (PHP + MySQL)**

### 🔹 **Responsive Design**
- Works smoothly on desktop, tablet, and mobile.
- Sidebar collapses on smaller screens.
